Access Without a Smartphone or Internet

Uganda has over 23 million mobile subscribersbut many rural patients use basic feature phones with no data access. MedLink solves this through three offline channels that work on anyphone with a SIM card.

USSD — Dial *280#
  • Works on any phone — even a UGX 15,000 handset
  • No internet or data plan required
  • Find nearest medicine in stock
  • Book a doctor appointment
  • Check wallet balance
  • Report a shortage
  • Get emergency numbers
Go live:Register at africastalking.com, create a USSD service on code *280#, point the callback URL to https://yourdomain.com/ussd/session
SMS — Text 8080
  • Text FIND Paracetamol— get nearest stock
  • Text BOOK— start appointment booking
  • Text BAL— check wallet balance
  • Text HELP— get all commands
  • Auto-replies with results in seconds
  • Appointment confirmations sent by SMS
Go live:Same Africa's Talking account. Buy a shortcode (8080), set inbound SMS callback to /ussd/sms/incoming. Add AT_API_KEYand AT_USERNAMEto .env.
IVR — Call 0800-MEDLINK
  • Toll-free voice call — works for illiterate patients
  • Press 1 for nearest pharmacy
  • Press 2 to hear doctor list
  • Press 3 for emergency services
  • Available in Luganda, Swahili, English
  • Voice read-back of appointment details
Go live:Africa's Talking Voice API. Register a toll-free number, build IVR flow in Python with text-to-speech, set callback to /ussd/ivr.
